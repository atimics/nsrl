# Deterministic Ising audit v1

This proposal-only audit derives an exact six-spin Ising representation from
the frozen p10m atomic-structure cube. It does not train a model, mutate an
optimizer state, read transfer documents, select a structure certificate, or
authorize scaling.

## Exact arithmetic

For vertex `x` and character `A`, the audit computes the unnormalized integer
Walsh coefficient

```text
W(A) = sum_x loss(x) (-1)^(A dot x).
```

With `s_i=(-1)^x_i`, the same coefficients are the integer numerators of the
Ising Hamiltonian

```text
loss(x) = (1/64) sum_A W(A) product_(i in A) s_i.
```

The replay checker independently verifies all 64 inversions and the integer
Parseval identity for Q20 and Q32.

Each frozen temperature uses a positive piecewise-linear dyadic weight. If
`delta=q*T+r`, then its common-scale integer weight is

```text
(2*T-r) 2^(127-q),  0 <= q < 128.
```

This avoids platform math libraries while retaining every vertex in the
ensemble. Reduced integer fractions record the ground-state probability,
expected excess energy, ground-state and Edwards--Anderson overlaps, per-spin
magnetic susceptibility, spin-glass susceptibility, and per-atom
magnetization.

The cubic Walsh residual is then streamed in binary-reflected Gray-code order
through a first-order sigma--delta quantizer with denominator `64`. Every row
records the input numerator, carry before, emitted integer, and carry after.
The checker enforces

```text
sum(input) = 64 sum(emitted) + final_carry
```

and the nearest-integer carry bound `|carry| <= 32`.

## Replay

Run:

```bash
scripts/run-production-atomic-ising-v1.sh
```

The checker regenerates the artifact in a temporary directory and requires
byte equality. The frozen contract binds the source result, source contract,
kernel, analyzer, checker, and the `integer_residual_sgd` optimizer control
tuple (optimizer name, state magic, and state version). Any change to those
bindings fails the audit until an explicit refreeze.

The frozen outputs are:

- `benchmarks/production-model-v1/p10m-atomic-ising-audit-v1-contract.json`
- `benchmarks/production-model-v1/p10m-atomic-ising-audit-v1.json`

The current passing replay hashes are emitted by
`scripts/run-production-atomic-ising-v1.sh` and independently checked against
freshly generated bytes.

## Prospective confirmation verdict

The frozen same-source confirmation on documents `136--199` **supported all
three preregistered endpoints** after exact Holm correction:

- pairwise Ising mask `59` versus baseline: `51/13/0`, aggregate Q32
  `-259574`;
- quenched-Gibbs mask `61` versus baseline: `50/14/0`, aggregate Q32
  `-257908`;
- the frozen `[47,59]` probe router versus global mask `47`: `17/0/47`,
  aggregate Q32 `-88447`.

This is a supported within-source confirmation, not a general Ising-model or
optimizer result. All proposal and confirmation documents come from one source
cluster, and that experiment alone does not identify cross-source
generalization. Documents `200--212` remain sealed, and the result authorizes
neither paid scaling nor an optimizer change. The default remains
`integer_residual_sgd`.

## Prospective cross-source certificate

MJ-17 subsequently tested the replicated conditional exchange prospectively on
a frozen 71-source distinct-author English Project Gutenberg frame. Whole
sources were split into 16 fitting, 39 conformal-calibration, and 16 untouched
evaluation panels. The source-level 95% correction is `4,326` Q32; all 16
evaluation panels are covered; 5 panels fire; all 5 fired exact contrasts are
favorable; and their aggregate is `-40,769` Q32. The source-role, panel,
predictor, score, abstention, and falsifier bindings replay through
`scripts/check-production-cross-source-exchange-v1.mjs`.

This establishes bounded prospective support for the conditional exchange on
that frame, not for the pairwise or Gibbs parameter maps and not for arbitrary
source deployment. The one-passage, two-target panel remains too narrow to
authorize an optimizer change or paid scaling.

MJ-18 widens the test to four publication families and four nonoverlapping
passages per source. Its whole-source split is 12 fitting, 76 family-specific
calibration, and 16 untouched evaluation panels. The rank-19 corrections are
`2,326` Q32 for Federal Register, `2,141` for Gutenberg, `4,307` for RFC, and
`4,272` for science. Fourteen of sixteen evaluation panels are covered. The
two failures are both Gutenberg panels, so the frozen overall decision is
`coverage_inconclusive_no_promotion`. Twelve passages fire across three
families; all have negative exact contrasts, none is unsafe, and net held-out
improvement is `63,541` Q32. Federal Register and RFC pass their frozen family
rules, Gutenberg is withheld by coverage, and science abstains. The result
replays through `scripts/check-production-multifamily-exchange-v1.mjs` and
does not authorize an optimizer change or paid scaling.
