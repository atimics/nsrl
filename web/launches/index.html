02 Six atoms enter the Forge

The useful result was “no.”

An atom is one small, reversible model change. We froze six of them, tried every combination, and kept the result that stopped the next expensive run.

  1. 01

    Freeze

    Lock six ordered moves, two exact objectives, the data boundary, and the checker.

  2. 02

    Try everything

    Evaluate all 64 subsets over 64 proposal documents: 8,192 exact forwards.

  3. 03

    Keep the “no”

    The compact rule chose a move already falsified on unused data. No scaling authorized.

What the cube actually says Structure observed

Interesting map. Rejected destination.

At Q32 precision, only 16 of 409,784 units of nonconstant interaction mass sat above order three. In plain language: this observed loss map was almost cubic.

But the exact support was still maximally tangled, every proposal document came from one source cluster, and the selected all-atom move had already lost its prospective test. Decision: do not scale.

The frozen confirmation then produced a sharper clue. Three narrow actions passed their within-source tests, but the pairwise and Gibbs maps changed. A probe router isolated a favorable atom exchange on all 17 documents it rerouted—even though always taking that exchange was worse overall. The partition, not a global winner, is the result.

    09 Gap analysis

    The local market works. The network comes next.

    The signed localnet covers identity, replay, sealed auctions, collateral, metering, quorum, challenges, expiry, and conserved test settlement. It deliberately stops before custody, transferable assets, or consensus.

    Recommended next build

    Durable multi-node testnet + artifact availability

    Move the deterministic reducer behind a durable API, replicate artifacts by content hash, and exercise validator and provider roles in separate processes without weakening evaluator-controlled promotion.

    1. Persist and index signed events
    2. Rotate keys and validator sets
    3. Replicate content-addressed artifacts
    4. Run timed challenge finality
